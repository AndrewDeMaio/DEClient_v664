00561     // -----------------------------------------------------------------------
00562     //  Private data members
00563     //
00564     //  fDefaultType
00565     //      Indicates what, if any, default stuff this attribute has.
00566     //
00567     //  fEnumeration
00568     //      If its an enumeration, this is the list of values as space
00569     //      separated values.
00570     //
00571     //  fId
00572     //      This is the unique id of this attribute, given to it when its put
00573     //      into the validator's attribute decl pool. It defaults to the
00574     //      special value XMLAttrDef::fgInvalidAttrId.
00575     //
00576     //  fProvided
00577     //      This field is really for use by the scanner. It is used to track
00578     //      which of the attributes of an element were provided. Any marked
00579     //      as not provided (after scanning the start tag) and having a
00580     //      default type of Required, is in error.
00581     //
00582     //  fType
00583     //      The type of attribute, which is one of the AttTypes values.
00584     //
00585     //  fValue
00586     //      This is the value of the attribute, which is the default value
00587     //      given in the attribute declaration.
00588     //
00589     //  fCreateReason
00590     //      This flag tells us how this attribute got created.  Sometimes even
00591     //      the attribute was not declared for the element, we want to fault
00592     //      fault it into the pool to avoid lots of redundant errors.
00593     //
00594     //  fExternalAttribute
00595     //      This flag indicates whether or not the attribute was declared externally.
00596     // -----------------------------------------------------------------------
